# ImplantDX MVP

Este es el prototipo funcional corregido, listo para subir a GitHub y conectar con Vercel.

## Deployment

This Next.js application is ready for deployment on Vercel. Simply connect your GitHub repository to Vercel and it will automatically deploy.

### Features

- Next.js application with proper structure
- Automatic PDF download functionality
- Static PDF file serving
- Optimized for Vercel deployment

### Development

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
npm start
```
